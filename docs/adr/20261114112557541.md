# ADR 20261114112557541 - Sensors send a label and a direction angle, never audio

- Status: accepted
- Date: 2026-11-14
- Source: human-decided
- Scope: system-wide

A sensor event carries the sound, its confidence, the time and one direction angle in degrees relative to the board: 0 = forward (marked on the board), increasing clockwise seen from above, 0 to 360, omitted when the sensor cannot tell. Never audio and never per-mic timings. The device owns its mic geometry, synchronisation and calibration; the server only knows each sensor's position and facing on the plan, and combines two sensors' angles into a location. This keeps the contract one number and lets the device team change their direction method freely.

## Consequences

The server must know each sensor's facing and position before it can place a sound. A mic sync or calibration problem must be fixed on the device; the server cannot correct it. Location uses only crossing directions from two sensors; there is no distance from a single sensor. A calibration run's report (ADR-20261114171057932) carries where in its own recording a sensor heard each beep and one bearing per beep, still never audio or per-mic timings.
