# ADR 20261114112557541 - Sensors send labels and raw mic delays, never audio; the server turns delays into direction

- Status: accepted
- Date: 2026-11-14
- Source: human-decided
- Scope: system-wide

A sensor event carries the sound, its confidence, the time and the three pairwise delays between its microphones, not an angle and never audio. The server holds each sensor's mic geometry, facing and per-mic delay corrections and computes direction and, with two sensors, location. This keeps the device side minimal and lets placement and calibration (facing typed by hand for now, a calibration step later, a fix for a mic that is out of sync) change on the server without touching devices.

## Consequences

The server must know each sensor's facing and position before it can place a sound. Location uses only crossing directions from two sensors; there is no distance from a single sensor.
