# ADR 20261114110501489 - EfficientAT mn10 as the fixed sound model, with small trained detectors on top

- Status: accepted
- Date: 2026-11-14
- Source: human-decided
- Scope: system-wide

Every sensor runs EfficientAT mn10_as (AudioSet pretrained, 4.9M parameters) unchanged, and each sound we alert on is a small detector trained on its 960-number embedding (about 4 KB). Alerts come from these detectors, not from the model's built-in 527 labels: in a crowd at equal loudness the built-in Chainsaw label caught 4/40 saws and a trained detector 37/40. A new sound is therefore a few-kilobyte update, never a new model.

## Consequences

The model and its preprocessing ship as one ONNX file (exported from PyTorch, matching it to about 1e-6), used unchanged on the sensor and in the researcher's browser. Every detector is tied to these exact model weights. Changing the model, its size variant or its audio preprocessing invalidates every deployed detector and means retraining and shipping a large update to every sensor. Built-in labels may still be reported as context, not used for alerting.

## Alternatives considered

Perch 2.0 (built for species, likely better on owls, untested on chainsaws), BirdNET (licence believed non-commercial) and YAMNet (weaker). Chosen without a head-to-head bake-off; the experiment folder's probe harness can run one if owl accuracy disappoints.

## History

- 2026-11-14: model and preprocessing packaged as one ONNX file, because browser-side training must compute the same embedding as the sensor.
