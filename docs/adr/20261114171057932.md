Pressing Calibrate makes 2 or 3 sensors that have a 3-mic array and a buzzer beep in turn. Each reports where in its own continuous recording it heard every beep and from which direction, never audio (ADR-20261114112557541); the service computes the distances by two-way ranging and each sensor's facing from the mutual bearings. Two-way ranging needs no shared clock: wall-clock time only schedules the slots and matches beeps to them, and never enters the distances. The layout is relative to the sensors: the first sensor on the plan is at the origin, the second straight to its right, and a third is placed by measurement. Two sensors whose bearings cannot give both facings calibrate the distance only: the first stays where it was placed, the second moves to the measured distance along the line to where it was placed, and both keep the facings set by hand. There is no anchor to the room, because sound alone cannot provide one and the demo needs none.

## Consequences

- A run changes the plan only when every check passes, in one batch; any failure names the board or pair and changes nothing, so the demo never shows a wrong layout. Manual placement stays as the fallback for a failed run and for any number of sensors, and a single sensor gives direction only. Dragging or turning a participant afterwards turns the plan back into a manual layout.
- Calibrate is a button only: no run starts when a board joins, there is no cancel, and one run at a time.
- Distance-only exists because the real hardware cannot measure facing: the Modulino Buzzer is nearly silent below 2.5 kHz, and above that the 4-7 cm mic spacing makes the three-mic bearing ambiguous, while the facing error matters more than the distance error for locating a sound (10 degrees is about 0.9 m at 5 m). Marking each board's forward and typing its facing is reliable; a failed run for want of a bearing was not.
- The service sets the sweeps and their timing in the run it sends, so they can be retuned once the real buzzer is measured on the stage without updating the boards.
- A new layout affects only new events: stored directions and locations stay as computed at arrival (ADR-20261114163418117). Calibration runs are not per-event records, and Clear events never touches them.
- The sensor contract gains a calibration plan in check-in replies and a calibration report from sensors. Sensors without a 3-mic array and a buzzer cannot take part. Three single-mic sensors cannot locate sounds: that would need sample-level clock sync and shared audio, which this design rules out.

## Alternatives considered

Typing one anchor (the first sensor's room position and facing) was rejected as unnecessary. Beep-and-reply ranging was rejected because the responder's reaction time is unknowable without the same self-recording two-way ranging already uses.
