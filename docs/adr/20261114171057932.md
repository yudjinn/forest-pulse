# ADR 20261114171057932 - Sensor layout is measured acoustically and is relative to the sensors

- Status: accepted
- Date: 2026-11-14
- Source: human-decided
- Scope: system-wide

Pressing Calibrate makes 2 or 3 sensors that have a 3-mic array and a buzzer beep in turn. Each reports the sample positions and bearings of every beep it heard; the service computes the distances by two-way ranging, which needs no shared clock, and each sensor's facing from the mutual bearings. The resulting layout replaces the plan when every check passes. It is relative to the sensors: the first sensor on the plan is at the origin, the second straight to its right, and a third is placed by measurement. There is no anchor to the room, because sound alone cannot provide one and the demo needs none. Manual placement stays as the fallback for a failed run and for any number of sensors; a single sensor gives direction only.

## Consequences

The sensor contract gains a calibration plan in check-in replies and a calibration report from sensors. Sensors without a 3-mic array and a buzzer cannot take part. Three single-mic sensors cannot locate sounds: that would need sample-level clock sync and shared audio, which this design rules out.

## Alternatives considered

Typing one anchor (the first sensor's room position and facing) was rejected as unnecessary. Beep-and-reply ranging was rejected because the responder's reaction time is unknowable without the same self-recording two-way ranging already uses.
