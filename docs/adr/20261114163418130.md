# ADR 20261114163418130 - Every stored record stays in the EU jurisdiction

- Status: accepted
- Date: 2026-11-14
- Source: feature/1#decision-6
- Scope: system-wide

The live D1 database was created in Cloudflare's EU jurisdiction, matching the R2 bucket, which already used it, so every record and file the service keeps stays in the EU (agent-made, confirmed by the user in the decision review). Default placement was rejected: it picks a location near the first request and could put records outside the EU, for a latency gain the demo does not need.

## Consequences

A D1 or R2 jurisdiction is fixed when the resource is created; wrangler.jsonc declares it for both so the deploy creates the database in it. Moving out of the EU, or back after a wrong creation, means a new database or bucket and copying the data across, which gets harder once real events exist. Every manual Wrangler call against the live bucket needs `--jurisdiction eu`.
