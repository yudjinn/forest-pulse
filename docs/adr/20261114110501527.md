# ADR 20261114110501527 - Server, dashboard and detector training run on Cloudflare

- Status: accepted
- Date: 2026-11-14
- Source: human-decided
- Scope: system-wide

The sensors talk directly over the internet to the deployed Cloudflare service at forestpulse.paxid.com, which hosts the device API, the researcher dashboard and storage. No laptop server, even for the demo, so the demo is the real architecture. Training a new detector needs the Python model code, which Workers cannot run, so it runs in a Cloudflare Container started by the Worker on demand.

## Consequences

Sensors need internet access at the venue (a captive-portal Wi-Fi blocks them), and the first training run after idle pays the container's cold start. Containers require the Workers Paid plan.
